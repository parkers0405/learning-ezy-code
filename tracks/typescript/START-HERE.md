# Start Here: TypeScript

You need Node.js 20+, Corepack, and an editor. From the repository root run:

```sh
corepack yarn install
corepack yarn language use typescript
corepack yarn roadmap
corepack yarn read --language typescript
```

Read the current textbook chapter, follow its link to the concise exercise contract, edit only learner files, run `corepack yarn test`, and submit locally with `corepack yarn submit`. Concepts are introduced just in time; begin at Part 0 even if you have seen JavaScript before, because later data-structure work depends on accurate runtime mental models.

After all 32 chapters pass, follow the root `ROADMAP.md` handoff to algorithms and LeetCode practice.
