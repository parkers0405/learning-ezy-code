# Start Here: TypeScript

You need Node.js 20+, Corepack, and an editor. From the repository root run:

```sh
corepack yarn install
./ezy install --shell
ezy use typescript
ezy start 1
ezy read
```

Read the current textbook chapter, follow its link to the concise exercise contract, edit only learner files, run `ezy test`, and submit locally with `ezy submit`. The `ezy` command works from any directory and remembers the active exercise. Concepts are introduced just in time; begin at Part 0 even if you have seen JavaScript before, because later data-structure work depends on accurate runtime mental models.

After all 32 chapters pass, follow the root `ROADMAP.md` handoff to algorithms and LeetCode practice.
