# TypeScript Track

Start with [`START-HERE.md`](START-HERE.md), then use `ezy start 1`. This track contains 51 strict-TypeScript workspaces in three ordered sections: 27 JavaScript runtime foundations, 16 TypeScript foundations, and 8 advanced TypeScript chapters.

Canonical lessons live in the ordered, offline [textbook](textbook/README.md). Every exercise links to one or more required readings and has an intentionally incomplete `starter.ts`, visible `exercise.test.ts`, concise contract, and isolated `.solution/`. JavaScript foundations still use `.ts` for strict feedback, while the textbook consistently distinguishes runtime JavaScript behavior from compile-time TypeScript checks.
