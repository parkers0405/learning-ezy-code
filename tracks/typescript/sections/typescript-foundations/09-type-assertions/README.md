# Type Assertions

**Required reading:** [Type Assertions](../../../textbook/typescript-foundations/09-type-assertions.md)

## Behavioral contract

Export `getStringLength(value: unknown)` returning the input string's character count, including zero-length and punctuation cases.

## Practice instruction

Use `value as string` as deliberate assertion practice. Visible tests enforce the `unknown` input, numeric result, and runtime examples; they cannot prove the exact assertion syntax used.
