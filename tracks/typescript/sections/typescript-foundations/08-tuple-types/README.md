# Tuple types

**Required reading:** [Tuple Types](../../../textbook/typescript-foundations/08-tuple-types.md)

## Behavioral contract

`displayTuple` accepts exactly `[string, number]` and formats tested values as `"The value for Age is 30."` and `"The value for Score is 0."`; reversed position types are rejected.

## Practice instruction

Keep the fixed tuple annotation and read its first and second positions by index when building the returned template literal.
