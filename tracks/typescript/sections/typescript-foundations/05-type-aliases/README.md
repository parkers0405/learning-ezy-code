# Type aliases

**Required reading:** [Type Aliases](../../../textbook/typescript-foundations/05-type-aliases.md)

## Behavioral contract

Export exact object type `Rectangle` with numeric `width` and `height`, and `computeArea(rect: Rectangle): number`. Area is width times height for ordinary and zero dimensions; invalid property types are rejected.

## Practice instruction

Keep `Rectangle` as a `type` alias and calculate from `rect.width` and `rect.height`. Do not replace the alias with a runtime constructor.
