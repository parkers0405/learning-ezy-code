# Interfaces

**Required reading:** [Interfaces](../../../textbook/typescript-foundations/06-interfaces.md)

## Behavioral contract

Export interface `Car` with `model: string` and `year: number`, plus `describeCar(car: Car): string`. It returns `"Tesla (2022)"` and `"Civic (1999)"` for the tested compatible objects; a string year is rejected.

## Practice instruction

Correct the property inside the supplied `interface Car` and keep `describeCar` reading through that interface. Do not add runtime validation or a class.
