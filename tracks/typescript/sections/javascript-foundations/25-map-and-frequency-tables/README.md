# Map and frequency tables

## Behavioral contract

For input `["a", "b", "a"]`, iterating the result of `frequencies` produces entries `[["a", 2], ["b", 1]]` in first-seen order.

## Practice instruction

Keep the `Map<string, number>` return contract and use the supplied `Map`, `for...of`, `.get`, `.set`, and `??` structure. The angle-bracketed tokens mean “string keys and number values”; tests prove the resulting entries, not that these operations produced them.
