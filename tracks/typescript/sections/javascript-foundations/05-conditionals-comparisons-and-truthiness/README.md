# Exercise: Conditionals, Comparisons, and Truthiness

**Prerequisites:** Complete the preceding roadmap entries.

**Required reading:** [Conditionals, Comparisons, and Truthiness](../../../textbook/javascript-foundations/05-conditionals-comparisons-and-truthiness.md)

## Contract

Export `firstDefined(a, b, c)`. Return the first value that is neither `null` nor `undefined`; `0` is valid and must be preserved. Tests distinguish nullish values from other falsy values. The supplied parameter annotations are test scaffolding; union types are taught formally later.

## Commands

Run `corepack yarn test`, `corepack yarn typecheck`, `corepack yarn submit`, or `corepack yarn solution` from this directory.
