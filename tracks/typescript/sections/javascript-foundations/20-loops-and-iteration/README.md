# Loops and iteration

## Behavioral contract

`sumUntilLimit` returns the sum before the next item would exceed `limit`. `countDown` joins every integer from `start` down to `1`.

## Practice instruction

Use the supplied `for...of` loop with `break` for the first function and the supplied `while` loop for the second. Write expanded assignments such as `total = total + value`; tests prove behavior, not loop syntax.
