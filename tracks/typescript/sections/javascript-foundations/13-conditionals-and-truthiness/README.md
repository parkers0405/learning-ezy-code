# Conditionals and truthiness

## Behavioral contract

Export `lowResult` as `"retry"`, `middleResult` as `"pass"`, and `highResult` as `"excellent"` for the supplied low, middle, and high scores.

## Practice instruction

Complete each statement-level `if / else if / else` chain. Do not replace the three branch traces with fixed exported strings; runtime tests verify results but cannot prove how you produced them.
