# Exercise: Loops and Iteration

**Prerequisites:** Complete the preceding roadmap entries.

## Contract

Export `formatBooks(titles, authors)` and use an indexed loop to collect matching entries as `title - author`, preserving array order. The arrays have matching lengths. Empty input returns an empty array.
