# Exercise: Objects, Properties, and Destructuring

**Prerequisites:** Complete the preceding roadmap entries.

**Required reading:** [Objects, Properties, and Destructuring](../../../textbook/javascript-foundations/09-objects-properties-and-destructuring.md)

## Contract

Export `describePlayer` and `withBonus`. Description output is `name: score`. `withBonus` returns a new player with the increased score, preserves other properties, and never mutates its input. The inline parameter shapes are supplied checking scaffolding; reusable type aliases are taught later. Tests include zero and identity checks.

## Commands

Run `corepack yarn test`, `corepack yarn typecheck`, `corepack yarn submit`, or `corepack yarn solution` from this directory.
